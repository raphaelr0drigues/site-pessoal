# Site Pessoal — Raphael Rodrigues

Projeto desenvolvido para a disciplina de Desenvolvimento Web (1º semestre de ADS — Universidade Braz Cubas), consolidando as entregas de **CP1 a CP4**.

🔗 **Site publicado:** https://raphaelr0drigues.github.io/site-pessoal/

## Páginas e Funcionalidades
- **Início (`index.html`):** Apresentação pessoal e interesses.
- **Currículo (`curriculo.html`):** Formação acadêmica, tabela responsiva de tecnologias, projetos e contato.
- **Formulário (`formulario.html`):** Formulário de contato com validação e feedback visual via JavaScript.
- **Multimídia (`multimidia.html`):** Reprodução de vídeo local, áudio MP3 e vídeo incorporado via `iframe`.
- **Gráficos (`graficos.html`):** Elementos gráficos criados com HTML5 Canvas e SVG.

## Evolução do Projeto (CP1 → CP4)
- **CP1:** Estruturação semântica em HTML5.
- **CP2:** Estilização e layout responsivo mobile-first com CSS Grid e Media Queries.
- **CP3:** Interatividade com JavaScript — alternância de tema claro/escuro com persistência em `localStorage` e validação de formulário.
- **CP4:** Integração do **Bootstrap 5** (`container`, `table-responsive`, `form-control`, `btn`, `badge`, `shadow-sm`) e ajustes de acessibilidade (contraste no dark mode, atributos `alt`/`title`, `aria-pressed` e foco visível para navegação por teclado).

## Tecnologias Utilizadas
- HTML5, CSS3 e JavaScript (ES6+)
- Bootstrap 5.3.8 (via CDN)
- Git e GitHub Pages
